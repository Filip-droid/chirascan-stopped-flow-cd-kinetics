StoppedFlowKinetiX for macOS
============================

Installing
----------
Drag StoppedFlowKinetiX onto the Applications folder in this window. Then eject
the disk image (the "StoppedFlowKinetiX" drive in Finder's sidebar).

The first start
---------------
StoppedFlowKinetiX is free software from a research institute. It is not signed
with a paid Apple developer certificate, so macOS stops it the first time:

1. Open StoppedFlowKinetiX from Applications. macOS says it cannot verify the
   app - click "Done" (or "OK"), do not move it to the Bin.
2. Open System Settings > Privacy & Security, scroll down to the message about
   StoppedFlowKinetiX and click "Open Anyway". Confirm with your password or
   Touch ID.
3. From now on StoppedFlowKinetiX opens normally.

The first start can take half a minute (preparing the plots); later starts are
faster.

Which version?
--------------
- ..._macOS_AppleSilicon.dmg: Macs with an M1, M2, M3, M4 ... chip (most Macs
  from 2021 on). See Apple menu > About This Mac > Chip.
- ..._macOS_Intel.dmg: older Macs with an Intel processor.
macOS 11 (Big Sur) or newer is needed.

Keyboard shortcuts
------------------
The help writes Ctrl+...; on the Mac use Cmd (⌘) instead, e.g. Cmd+O to open a
folder and Cmd+S to save a project.

Your files
----------
Automatic saves, the log and the help pages are kept in
~/Library/Application Support/StoppedFlowKinetiX. To uninstall, move the app
to the Bin (and delete that folder if you want).

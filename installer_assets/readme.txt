
StoppedFlowKinetiX 2.0.0
========================

StoppedFlowKinetiX analyses stopped-flow circular dichroism (CD) kinetics
exported from an Applied Photophysics Chirascan: it averages the chosen
repeats, removes the dead-time points, subtracts the baseline, converts the
signal from mdeg to molar circular dichroism (delta epsilon), fits one-,
two- and three-exponential association and one- and two-phase decay models
(95 % confidence intervals, time constants, half-lives, R2, RMSD, AIC, BIC,
Durbin-Watson, multi-start check), compares the models (F-test of nested
models) and exports everything to a single-sheet Excel workbook.

The analysis is that of the Jupyter notebook
"G4_stopped_flow_kinetic_analysis" by Filip Krikava
(https://github.com/Filip-droid/chirascan-stopped-flow-cd-kinetics,
DOI 10.5281/zenodo.23059866) - please cite it if you use the program.

Getting started
---------------

Start the program, press "Example" in the toolbar and follow
Help > Quick start. F1 searches the whole help; the orange "?" buttons
explain each part of the window.

Uninstalling
------------

Start menu > StoppedFlowKinetiX > Uninstall StoppedFlowKinetiX, or
Windows Settings > Apps.

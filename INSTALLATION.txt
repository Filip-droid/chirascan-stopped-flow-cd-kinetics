StoppedFlowKinetiX - installation
=================================

1) Installed version (Windows)
   Run installer\Setup_for_StoppedFlowKinetiX_ver_<version>.exe.

1b) Installed version (macOS)
   Download StoppedFlowKinetiX_<version>_macOS_AppleSilicon.dmg (M1 or newer)
   or ..._Intel.dmg from the GitHub release, open it and drag the app onto
   Applications. First start: open it, click "Done", then System Settings >
   Privacy & Security > "Open Anyway" (the app is not signed by Apple).
   The .dmg files are built by .github/workflows/build-macos.yml when a
   release is published (or by hand: Actions > Build macOS app > Run workflow).

2) From the source code
   Easiest: double-click setup_env.bat. The first time it creates the
   project's own Python environment in the folder "StoppedFlowKinetiX_env"
   (naming: <Project>_env), installs the packages, runs the tests and puts
   the folder "StoppedFlowKinetiX (Python)" on the desktop with four
   shortcuts: "StoppedFlowKinetiX" starts the program,
   "StoppedFlowKinetiX_env Terminal" opens a command prompt in the project
   folder with the environment active (python main.py, python -m pytest,
   BuildInstaller.bat), "Run tests" and "Build installer" open that
   terminal and run the tests or BuildInstaller.bat. Run again (e.g. after an update),
   it keeps the environment and only installs missing or changed packages -
   a few seconds.
     setup_env.bat fresh        rebuilds the environment from scratch
     setup_env.bat fresh 3.12   ... with a specific Python version
   Packages: requirements-lock.txt (the exact versions of every library)
   when it was made with the same Python version as the environment's -
   so a second computer with that Python gets exactly the same versions -
   otherwise requirements-dev.txt (requirements.txt + PyInstaller). The
   first run without a lock file writes requirements-lock.txt.
   An environment cannot be copied to another computer: get the project
   with git and run setup_env.bat there. (The folder "venv" of earlier
   versions of the script is no longer used and can be deleted.)
   Python is found through the py launcher (python.org), "python" on PATH
   or an Anaconda / Miniconda installation in its usual folder. With
   Anaconda, running the script from the "Anaconda Prompt" is the safest.

   By hand:
   python -m venv StoppedFlowKinetiX_env --prompt StoppedFlowKinetiX_env
   StoppedFlowKinetiX_env\Scripts\activate
   pip install -r requirements.txt
   python main.py            (or double-click run.bat)

3) Tests
   python -m pytest          (or tools\run_tests_windows.bat)

4) Building the installer
   pip install pyinstaller
   install Inno Setup 7 or 6 (https://jrsoftware.org/isinfo.php, default folder)
   BuildInstaller.bat

   The version is taken from src\version.py. To redraw the icons and
   installer images: pip install pillow, python tools\make_icons.py

StoppedFlowKinetiX - installation
=================================

1) Installed version (Windows)
   Run installer\Setup_for_StoppedFlowKinetiX_ver_<version>.exe.

2) From the source code
   Easiest: double-click setup_environment.bat. The first time it creates a
   Python environment in the folder "venv", installs the packages, runs the
   tests and puts the shortcut "StoppedFlowKinetiX (Python)" on the desktop.
   Run again (e.g. after an update), it keeps the environment and only
   installs missing or changed packages - a few seconds.
     setup_environment.bat fresh        rebuilds the environment from scratch
     setup_environment.bat fresh 3.12   ... with a specific Python version

   By hand:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python main.py            (or double-click run.bat)

3) Tests
   python -m pytest          (or tools\run_tests_windows.bat)

4) Building the installer
   pip install pyinstaller
   install Inno Setup 6 (https://jrsoftware.org/isinfo.php)
   BuildInstaller.bat

   The version is taken from src\version.py. To redraw the icons and
   installer images: pip install pillow, python tools\make_icons.py
